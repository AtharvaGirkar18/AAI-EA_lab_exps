# Agentic AI and Automation Lab Projects

A monorepo containing four independent classroom and portfolio projects. Each project has its own README, requirements, sample data, and run instructions.

## Projects

| Project | Description | Start here |
|---|---|---|
| Intelligent Customer Support | Streamlit support workflow using local Ollama Qwen, approved knowledge retrieval, risk routing, batch evaluation, and MCP tools. | [Project README](IntelligentCustomerSupport/README.md) |
| Automated Recruitment Workflow System | Auditable recruitment workflow with synthetic candidate data, deterministic evaluation, MCP tools, and local Qwen explanations. | [Project README](AutomatedRecruitmentWorkflowSystem/README.md) |
| Developer Automation System | Developer request planning, supervised MCP tool execution, code corpus search, validation, and batch evaluation. | [Project README](DeveloperAutomationSystem/README.md) |
| Ecommerce Product Analysis and Recommendation | Product discovery, filtering, comparison, budget-aware recommendations, and workflow traces over a sample catalog. | [Project README](EcommerceProductAnalysisAndRecommendation/README.md) |

## Setup

Projects are independent. Open the project folder, follow its README, and create a separate Python virtual environment there. Some workbenches use the same default port, so run those projects one at a time or configure a different port as described in their README.

Sample data is included where the project uses it. Runtime logs, local databases, virtual environments, caches, and rendered review files are excluded from Git.
